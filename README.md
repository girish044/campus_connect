# 🎓 CampusConnect – College Buy & Sell Marketplace

CampusConnect is a web-based marketplace designed exclusively for college students. The platform allows students to buy and sell used items within their campus community, making transactions more affordable, convenient, and trustworthy.

## 🚀 Features

### 👤 User Authentication

* User Registration
* User Login
* Secure Session Management

### 🛍 Marketplace

* Post Items for Sale
* Browse Available Listings
* View Product Details
* Delete Own Listings

### 📚 Supported Categories

* Books
* Notes
* Electronics
* Hostel Essentials
* Cycles
* Furniture
* Other Student Items

### 👤 User Profile

* View Personal Information
* Manage Listings
* Track Posted Items

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/girish044/campus_connect.git
cd campus_connect
```

### Run Backend

```bash
mvn spring-boot:run
```

### Open Application

```text
http://localhost:8080
```

## 🎯 Project Objective

The primary objective of CampusConnect is to provide students with a dedicated platform where they can exchange useful items within their college community, reducing costs and promoting resource sharing.
